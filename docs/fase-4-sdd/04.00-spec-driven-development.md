# 04.00 Spec-Driven Development

## Slice inicial formalizado

La primera feature canónica del brownfield es:

- `specs/001-checkout-payments/`

Su objetivo es homologar:

- checkout público;
- pago manual con comprobante;
- conciliación operativa manual;
- frontera futura de `payment-gateway` idempotente.

## Regla de esta fase

- No inventa una feature abstracta ni desconectada del runtime.
- Parte del código vivo y de los flujos operativos documentados.
- Toda evolución futura de checkout/pagos debe aterrizar sobre esta carpeta o una feature sucesora claramente trazada.
