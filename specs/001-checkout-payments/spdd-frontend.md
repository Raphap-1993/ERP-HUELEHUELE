# SPDD Frontend - Checkout Payments

## Alcance visual

El slice visual homologado cubre:

- wizard de checkout;
- ruta manual visible;
- instrucciones y carga de comprobante;
- claridad operativa entre `Pagos` y `Pedidos > Operacion`.

## Regla de SPDD

- no se abre un rediseño nuevo;
- se toma el runtime actual como baseline visual;
- la homologación solo fija intención, límites y evidencia para que futuras mejoras no rompan el flujo.
