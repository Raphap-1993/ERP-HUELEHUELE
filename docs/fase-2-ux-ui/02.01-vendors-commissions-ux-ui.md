# Fase 2 - UX/UI Vendors Commissions

## Objetivo

Formalizar la UX del flujo seller-first vigente sin redisenar las superficies ni
convertir la homologacion en un frente de polish visual.

## Fuentes de runtime

- `apps/web/components/seller-panel-workspace.tsx`
- `apps/admin/components/orders-workspace.tsx`
- `apps/admin/components/commissions-workspace.tsx`
- `docs/flows/vendor-application.md`
- `docs/flows/commercial-accesses.md`

## Superficies

### `/trabaja-con-nosotros`

- captura de postulacion publica
- no crea cuenta comercial
- debe sentirse como puerta de entrada al canal seller-first, no como alta inmediata

### `/panel-vendedor`

- superficie operativa real del vendedor
- muestra metricas, comisiones, payouts y estado comercial
- no recalcula negocio ni corrige atribucion

### `/admin/vendedores`

- alta, aprobacion, estado y acceso comercial
- aqui vive la gestion de perfil, codigo y vinculacion operativa del vendedor

### `/admin/comisiones`

- reglas, comisiones y payouts
- refleja consecuencia financiera y vida comercial del canal seller-first

### `Pedidos > Operacion`

- punto unico de correccion de atribucion post-pedido
- no debe sentirse como formulario libre de reasignacion

## Contrato UX del slice

- el canal seller-first debe leerse como flujo continuo entre postulacion, venta y payout
- el vendedor externo no ve superficies internas de revision o auditoria
- el seller manager si ve aprobacion, reglas y payouts desde admin
- la correccion de `vendorCode` debe verse como excepcion operativa, no como edicion rutinaria

## Regla UX critica

- la correccion de `vendorCode` no debe parecer una edicion libre
- si el pedido ya cruzo lock financiero, la UI debe bloquear la accion; este slice no define una superficie canonica post-lock
- `/admin/comisiones` no debe prometer que corrige la atribucion primaria
- `/panel-vendedor` solo muestra verdad derivada y estados ya consolidados

## Criterio de cierre

- las superficies seller-first quedan nombradas y delimitadas
- el contrato UX no contradice el runtime vigente
- Fase 3 puede heredar esta lectura sin reabrir el diseno del producto
