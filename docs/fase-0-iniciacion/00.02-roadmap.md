## Corte actual
- El software base ya esta vivo en `web`, `admin`, `api` y `worker`.
- La prioridad metodologica inmediata es ordenar la capa canonica sin borrar la
  documentacion que hoy sostiene la operacion.
- La prioridad funcional inmediata sigue en catalogo, media administrable,
  persistencia real de productos y cierre de brechas UX/comerciales pendientes.

## Track A: homologacion brownfield
| Hito | Estado | Salida esperada |
|---|---|---|
| Raiz canonica + Fase 0 | Cerrado en este corte | `AGENTS.md`, `AI_CONTEXT.md`, `PROJECT_MAP.md`, `TRACEABILITY_MATRIX.md`, `GLOSSARY.md`, `docs/fase-0-iniciacion/` |
| Fase 1 y Fase 2 canonicas | En paralelo | Requerimientos, reglas, casos de uso y UX formalizados desde `docs/flows/` y `docs/ux/` |
| Fase 3 + specs base | En paralelo | Arquitectura canonica, ADRs y primera capa `specs/` |
| Fases 5 a 8 canonicas | En paralelo | Construccion, QA, deploy y operacion mapeados sobre el runtime real |

## Track B: producto y operacion
| Frente | Prioridad | Resultado esperado |
|---|---|---|
| Catalogo y media administrable | Alta | CRUD real de productos y fuente persistida de catalogo para storefront y checkout |
| Media publica | Alta | Pipeline hacia `Cloudflare R2` para logo, hero, banners e imagenes de producto |
| Automatizacion comercial | Media | Campanas, segmentos y promociones menos manuales |
| Refinamiento UX final | Media | Homologacion visual consistente entre rutas publicas y administrativas |
| Escala controlada | Media | Reporting, loyalty y automatizacion mas profundos sin romper el monolito modular |

## Base ya entregada
- Storefront y backoffice funcionales.
- Checkout, pedidos, pagos y revision manual operando.
- Vendedores, comisiones, mayoristas, loyalty, CMS y dashboards ya presentes.
- Persistencia en `PostgreSQL`, colas en `Redis/BullMQ` y despliegue reproducible en VPS.

## Regla de lectura
Este roadmap convive con el roadmap funcional vigente: una cosa es la
homologacion documental del brownfield y otra la evolucion del producto vivo.
Ambas deben avanzar coordinadas, pero no significan lo mismo.
